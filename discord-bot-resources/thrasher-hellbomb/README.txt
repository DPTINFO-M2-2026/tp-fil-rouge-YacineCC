💣 THRASHER HELLBOMB VIDEOS
===========================

Mets tes vidéos Hellbomb de Thrasher ici !

🎥 Format accepté : MP4, MOV, AVI, WEBM
📏 Taille max : 8 MB (limite Discord standard) ou 50 MB (Discord Nitro)

⚠️  ATTENTION : Discord a des limites de taille strictes !
- Sans Nitro : 8 MB maximum
- Avec Nitro : 50 MB maximum

💡 Conseils :
- Privilégie les fichiers MP4 (meilleure compatibilité)
- Compresse tes vidéos si elles dépassent 8 MB
- Utilise des noms descriptifs sans espaces

📝 Exemples de noms de fichiers :
---------------------------------
✅ hellbomb_aaron_homoki_lyon.mp4
✅ hellbomb_jaws_25_stairs.mp4
✅ hellbomb_ali_boulala_macba.mp4
✅ thrasher_hellbomb_compilation_01.mp4

❌ évite : "ma video.mp4" (espaces)
❌ évite : "vidéo@#$.mp4" (caractères spéciaux)

🚀 Pour lancer le bot avec les vidéos :
---------------------------------------
1. Ajoute tes vidéos MP4 dans ce dossier
2. Lance le bot : ./run-thrasher-bot.sh
3. Dans Discord : !thrasher hellbomb

💣 Une vidéo aléatoire sera postée ! 🛹✨
