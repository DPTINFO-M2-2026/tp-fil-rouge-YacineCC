📁 THRASHER COVERS
==================

Mets tes images de covers Thrasher Magazine ici !

🖼️ Formats acceptés : JPG, JPEG, PNG, GIF
📏 Taille max : 8 MB (limite Discord)

📝 Conseils pour nommer tes fichiers :
--------------------------------------
✅ thrasher_1981_janvier.jpg
✅ thrasher_tony_hawk_1999.jpg
✅ thrasher_vintage_001.png
✅ thrasher_anniversary_40ans.jpg

❌ évite les espaces : "cover thrasher.jpg"
❌ évite les caractères spéciaux : "cover@#$.jpg"

🎯 Organisation suggérée :
-------------------------
Tu peux créer des sous-dossiers si tu veux organiser :
- thrasher-covers/vintage/
- thrasher-covers/2000s/
- thrasher-covers/skateurs/

Mais pour l'instant, le bot lit SEULEMENT les images
dans ce dossier principal (pas les sous-dossiers).

🚀 Une fois que tu as ajouté des images :
-----------------------------------------
Lance le bot avec :
  ./run-thrasher-bot.sh

Ou :
  mvn exec:java -Dexec.mainClass="fr.univtln.yhaouas846.discord4j.ThrasherBot"

Puis dans Discord, tape :
  !thrasher

Et une cover aléatoire sera postée ! 🛹✨

Note: Ce fichier README ne sera PAS posté par le bot,
il est juste là pour t'aider à organiser tes images.
