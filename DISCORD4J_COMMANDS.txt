🤖 COMMANDES RAPIDES - Bot Discord4J
=====================================

📝 AVANT DE COMMENCER
---------------------
1. Crée ton bot sur : https://discord.com/developers/applications
2. Active "MESSAGE CONTENT INTENT" dans Bot Settings
3. Copie le TOKEN
4. Remplace "TOKEN" dans MyBot.java ligne 26


🚀 LANCER LE BOT
----------------
# Méthode 1 : Avec le script
./run-discord-bot.sh

# Méthode 2 : Avec Maven directement
mvn exec:java -Dexec.mainClass="fr.univtln.yhaouas846.discord4j.MyBot"


📁 FICHIERS IMPORTANTS
----------------------
src/main/java/fr/univtln/yhaouas846/discord4j/
├── MyBot.java                    ← Le bot ping/pong principal
├── README_DISCORD4J.md           ← Documentation complète
└── examples/
    └── TutorialExamples.java     ← Pour tester d'autres exemples


💬 TESTER LE BOT
----------------
Dans Discord, écris :
  ping ?

Le bot répond :
  pong !


🎓 EXEMPLES À ESSAYER
---------------------
Une fois que ping/pong fonctionne, colle les exemples du tuto Discord4J
dans TutorialExamples.java et lance-le :

mvn exec:java -Dexec.mainClass="fr.univtln.yhaouas846.discord4j.examples.TutorialExamples"


⚠️  RAPPELS IMPORTANTS
----------------------
❌ NE COMMIT JAMAIS TON TOKEN sur Git !
✅ Pense à activer MESSAGE CONTENT INTENT
✅ Invite le bot sur ton serveur avec les bonnes permissions

🐛 EN CAS DE PROBLÈME
---------------------
Le bot ne répond pas ?
  → Vérifie MESSAGE CONTENT INTENT
  → Vérifie les permissions du bot

Erreur de connexion ?
  → Vérifie que le TOKEN est correct
  → Vérifie ta connexion internet

Le bot se déconnecte ?
  → Regarde les logs d'erreur dans la console


Bonne chance ! 🚀
